# Picked Up, Not Given Back

A one-line entry for make.fun's **One-Liner Laugh Lab**: the excuse a robot
vacuum gives after eating a sock. The vacuum followed its instructions to the
letter — it picked the sock up; nobody ever mentioned giving anything back.

The program (`main.ts`, Node, program/v1) writes the line to
`/output/entry.txt`, checking it against the competition gate (1–200
characters) and verifying the written file byte for byte.
